# Security Policy

## Supported versions

Security fixes target the latest stable RTBus runtime firmware and RTDuo Arduino
platform releases. Reports about earlier versions are welcome. Include the
versions you tested and whether the issue also affects the latest release, if
known.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/hudec-iot/rtbus/security/advisories/new)
to report a suspected security issue in RTBus or RTDuo. If the form is
unavailable, open a [GitHub issue](https://github.com/hudec-iot/rtbus/issues/new)
asking the maintainers for a private reporting channel. Keep vulnerability
details and attachments out of public issues, discussions, and pull requests.

Include the affected component, release versions or commit IDs, board profile,
relevant configuration, steps to reproduce, and expected security impact.
Remove credentials, private signing keys, and other sensitive data from logs
and attachments.

Please coordinate public disclosure with the maintainers through the private
report.
